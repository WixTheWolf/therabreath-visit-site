Site Parity Validation Program

A validation program to confirm taste consistency as production expands across sites — same formulations, same TFF flavors, and robust data on whether a difference exists and what it is.

8 variants · phased through Sep 2026 Triangle + blind paired methods Expert → analytical → consumer escalation
"We need to generate a robust data set that informs us if there is or is not a difference in the taste, and if there is a difference, what the difference is." — Ross Conroy, Sr. Fragrance & Flavor Development Specialist · Church & Dwight · Lakewood implementation request

TFF proposes a four-rung escalation ladder — each rung answers a sharper question. Most variants stop at Rung 2 with a clear pass/fail. Flagged variants climb to descriptive and, for tier-A SKUs, consumer confirmation. Every step uses blind coding, randomized presentation order, and documented statistical thresholds.

Escalation ladder

1

Expert screening (TheraBreath R&D)

Same as NPD — your team tastes Lakewood vs reference site samples side-by-side. Same/different decision + informal attribute notes. Go/no-go for formal panel. Already in your workflow; we align on coding and protocol.

Expert SOP →
2

Triangle test — "Is there a difference?"

ISO 4120 triangle test. Panelists receive three coded samples (two reference site, one Lakewood — or balanced design). Forced choice: which is the odd sample? α = 0.05, powered for pd = 30–40%. Primary gate for site parity.

Triangle kit →
3

Blind paired comparison — "What is the difference?"

Only if triangle is significant. Duo-trio (match-to-reference) plus 15-point attribute scales: mint intensity, sweetness, cooling, mouthfeel, aftertaste, chlorite character. Builds the flavor fingerprint delta report.

Blind test kit →
4

Consumer validation — "Does it matter in market?"

Tier-A variants only (Icy Mint, Sparkle Mint). 100+ blind CLT or HUT respondents. Overall liking + purchase intent. Confirms business significance of any analytical difference found.

What TFF brings

Flavor-side expertise

  • We supplied every flavor in the trial matrix — we know the intended sensory target
  • Retain library of reference-site production samples for true A/B
  • Chlorite-stability context: what shifts are process vs flavor vs base

Execution support

  • Blind sample coding SOP + random 3-digit code generator
  • Print-ready triangle and paired ballots (in toolkit)
  • Significance calculator + results report template
  • Variant tracker shared with Ross's timeline

Panel design

  • Triangle: min 24 panelists (30 preferred), α=0.05, β=0.20
  • Blind paired: min 20 panelists per variant
  • Consumer: 100+ for tier-A; partner with C&D or third-party CLT
  • Wash protocol: water + unsalted crackers between samples

Decision rules

  • Pass: Triangle not significant (p ≥ 0.05) → site parity confirmed
  • Flag: Triangle significant → blind paired + fingerprint report within 5 business days
  • Escalate: Attribute delta > 1.0 scale point on any key driver → joint R&D working session
  • Consumer: Tier-A only if analytical difference confirmed
