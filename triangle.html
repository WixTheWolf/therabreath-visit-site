Triangle test kit

Determine whether Lakewood production tastes different from reference site — blind, forced choice, statistically powered.

When to use

Primary gate after expert screening. Two samples from reference manufacturing site (A) + one from Lakewood trial (B), presented as three coded cups. Panelist identifies the odd sample. Balanced design: 50% of panelists get AAB, 50% get ABB.

Panel requirements

  • Minimum 24 panelists (30 recommended) — trained or semi-trained
  • α = 0.05 · target power 80% to detect pd = 30%
  • Same rinse volume (10 mL), 15-second swish, expectorate
  • Wash: water rinse + unsalted cracker · 2 min between sets
  • Room: neutral lighting, no fragrance, 20–22 °C

Sample prep & blinding

  1. Pull reference-site retain + Lakewood trial pull at same age (±3 days if possible)
  2. Code with random 3-digit numbers — never reuse codes across variants
  3. Prepare in separate area; only the pour technician knows the key
  4. Present in random order per panelist (use ballot set A or B)
  5. Record: variant, panelist ID, ballot set, selected odd sample, correct/incorrect

Decision rule

Not significant (≥ pass): Correct count ≤ critical value at α=0.05 → no detectable difference; site parity confirmed for this variant.

Significant (flag): Correct count > critical value → escalate to blind paired comparison within 5 business days. Do not release to consumer testing until fingerprint is understood.
