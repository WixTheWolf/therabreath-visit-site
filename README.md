# Breath of Innovation | The Flavor Factory x TheraBreath

Capabilities workshop site for the TheraBreath (Church & Dwight) visit on **July 8, 2026** at The Flavor Factory in Norco, California.

## What this site covers

- Partnership overview and visit objectives
- Four capability pillars: Resiliency, Innovation, Supply Chain, Partnership Vision
- Flavor trends and prototype concepts for the tasting workshop
- Sensory evaluation guide and feedback capture
- Next steps and contact information

## Local preview

Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy

This is a static site. Deploy to Vercel from the repository root:

```bash
vercel --prod
```
